# v2.1-T5: OpenCode V2 Compaction 前自动沉淀到 daily

## 目标

在长对话触发上下文压缩时，自动将尚未落盘的关键决策、用户偏好与排错结论追加到当日 `daily/YYYY-MM-DD.md`，避免信息随压缩丢失。

## 改动

1. `SessionStateStore.ts`：记录每个 `sessionID` 已完成 compaction flush 的标记/消息游标，保证单次压缩周期最多执行一次。
2. 新增 `hooks/registerCompactionFlush.ts`：
   - 注册 `ctx.session.hook("compaction", async (event) => ...)`。
   - 从 `event.messages` 抽取最近未沉淀对话摘要（裁剪冗长 tool output）。
   - 调用 `ctx.experimental.generate.text(...)`（超时保护 `8000ms`，异常捕获静默降级，**绝不阻塞 compaction**）提炼高价值待记条目。
   - 若返回非 `NO_MEMORY`，调用 `memoryManager.appendFile()` 写入当前项目或全局 `daily/YYYY-MM-DD.md`（标记 `origin: agent`）。
   - 向 `event.system` 追加轻量提示，避免压缩摘要重复冗长复述已落盘细节。
3. 在 `index.ts` 注册该 hook，支持配置项 `options.compactionFlush` 开关（默认开启）。

## 验收

- 触发 `compaction` hook 时能将关键决策写入对应作用域的 `daily/YYYY-MM-DD.md`。
- 同一压缩周期重复触发只执行一次 flush。
- `experimental.generate.text` 报错或超时时，`compaction` hook 正常返回且不抛出未捕获异常。
