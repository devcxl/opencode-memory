# v2.1-T6: /memory-consolidate 按需记忆蒸馏命令

## 目标

提供开发者可控的显式 Slash Command，将近期 `daily/` 中跨会话有价值的知识蒸馏归并到当前作用域 `MEMORY.md`，并在字符预算内清理过时条目。

## 改动

1. 新增 `commands/registerMemoryConsolidateCommand.ts`，通过 `ctx.command.transform` 注册 `memory-consolidate`。
2. 解析可选天数参数（默认 `7` 天），读取对应项目（无项目时全局）近期 `daily/*.md` 与当前 `MEMORY.md` 及字符预算余量。
3. 过滤或显式标注 `origin: external` 条目，禁止未经确认将外部信息自动晋升为常驻核心记忆。
4. 通过 `ctx.session.prompt(...)` 下发结构化整理指令，引导模型使用 `memory` 工具（含 `replace_timestamps` / `edit` / `delete`）完成合并与退休旧条目。
5. 在 `index.ts` 注册命令，所有改动由既有 `gitCommit` 自动留痕。

## 验收

- `/memory-consolidate` 可正确识别项目级与全局级作用域。
- 汇总提示包含当前 `MEMORY.md` 字符占用率与预算上限。
- 仅修改 `MEMORY.md` 时有完整 Git commit 记录，支持一键 `git revert`。
