# v2.1-T3: Hybrid 混合检索、分层时间衰减与去重

## 目标

解决纯向量检索对代码符号/环境变量/错误码召回弱、旧 `daily` 干扰近期记忆、以及写入时 O(N) 重复 embedding 问题（整合 `#29`, `#30`, `#31`, `#32`, `#36`）。

## 改动

1. `search/chunker.ts`（`#30`）：切片生成嵌入文本时注入文件与标题面包屑，并增加超长 chunk（1200 chars / overlap 150）切分兜底。
2. `search/vector-store.ts`（`#32`）：`upsertFile` 先比对已有切片 `hash`，仅对新增/变更块调用 `embedText()`。
3. 新增 `search/bm25.ts`：纯 TypeScript 轻量 BM25（支持驼峰、下划线、点号分隔标识符切词），覆盖 `scope` 内全局与项目 `.md` 文件，支持按 `period` 前置过滤（`#31`）。
4. `memory/FileSearcher.ts`（`#29`）：
   - 接入向量（0.70）+ BM25（0.30，经反饱和归一化）混合打分；
   - `minScore`（0.25）在时间衰减**前**过滤；
   - `MEMORY.md`/`USER.md`/`IDENTITY.md` 不衰减，`daily/YYYY-MM-DD.md` 按 `exp(-(ln2/30)*ageDays)` 衰减；
   - 轻量 MMR（`lambda = 0.7`）去重。
5. `handlers/handleList.ts`（`#36`）：让 `list` 感知 `projectId` 与 `scope`。

## 验收

- 搜索精确符号（如 `OPM_EMBEDDING_DTYPE`、`P2002`）稳定命中前 3。
- `minScore` 过滤先于时间衰减执行；`MEMORY.md` 分数不随时间衰减。
- 同日 `daily` 多段相似文本不再霸占前排结果。
- 未修改的切片在追加写入时不触发 `embedText()`。
