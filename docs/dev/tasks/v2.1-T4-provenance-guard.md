# v2.1-T4: 轻量 Provenance 来源标记与自动注入安全隔离

## 目标

防止网页抓取、外部检索结果或不可信工具输出通过 `memory(write)` 回流进每轮自动注入的长期上下文。

## 改动

1. `utils/timestampParser.ts`：扩展解析 `<!-- YYYY-MM-DD HH:MM:SS | origin: owner|agent|external -->`；无 `origin` 属性的存量条目向后兼容视为 `agent`。
2. `tool/schema.ts` & `handlers/handleWrite.ts`：
   - 增加可选入参 `origin: z.enum(["owner", "agent", "external"]).optional()`（默认 `"agent"`）。
   - `origin === "external"` 尝试写入 `target === "memory"` 时拒绝并提示改写到 `daily`。
3. `MemoryManager.ts` / `index.ts`：`buildContext()` 构建注入文本时过滤掉 `origin: external` 的块（保留在磁盘文件与 `search` 检索中）。
4. `deleteByTimestamp` 保持按时间戳前缀兼容匹配带 `origin` 属性的注释行。

## 验收

- 旧格式 `<!-- 2026-11-21 10:00:00 -->` 读写删除 100% 兼容。
- `origin: external` 不允许直接写入 `memory`，且即使手工存在于文件中也不会被 `buildContext()` 自动注入。
- 带 `origin: external` 的 `daily` 条目仍可通过 `memory(search)` 或 `memory(read)` 主动查到。
