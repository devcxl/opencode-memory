# v2.1-T1: SystemPart 分层与会话级冻结快照

## 目标

消除每轮 `ctx.session.hook("context")` 从磁盘重读拼接导致的 KV Cache 前缀抖动，实现“同会话前缀字节稳定 + 本会话写后精准失效”。

## 改动

1. 新增 `SessionContextCache`（按 `sessionID` 缓存 `Memory Context` 注入正文及 `bootstrapNeeded` 状态）。
2. 修改 `apps/plugin/src/index.ts` `ctx.session.hook("context")`：
   - 拆分为最多 3 个 `SystemPart`：
     - Part 1（纯静态）：`getMemoryInstructions()`
     - Part 2（冻结快照）：`SessionContextCache.getOrBuild(sessionID, projectId, buildContext)`
     - Part 3（动态尾部，按需）：`## Memory Reminder`
3. 修改 `ctx.tool.hook("execute.after")`：
   - 仅当 `event.tool === "memory"`、`event.status === "completed"`、且写入改变了注入文件（`target` 为 `memory` / `identity` / `user` / `bootstrap`）时调用 `contextCache.invalidate(event.sessionID)`。
   - `target === "daily"` 写入成功**不**触发缓存失效。
4. 在 `session.deleted` 与插件 cleanup 中清理对应 `sessionID` 缓存。

## 验收

- 同一 `sessionID` 连续两次调用 `buildSystem()`，在未修改注入文件时只读取一次磁盘，输出完全一致。
- 写入 `daily` 后，Part 1 与 Part 2 字节不变。
- 写入 `memory` / `user` / `identity` 后，下一次 `buildSystem()` 立即体现最新内容。
- `session.deleted` 后缓存被释放。
